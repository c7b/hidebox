What breaks walletd 0.45.0 (PR #2859, merged 2026-10-09, 'feat(engine)!: stop recording template
return values in the transaction result'):

      #[n(0)] pub transaction_hash: Hash32,
      #[n(1)] pub events: Vec<Event>,
      #[n(2)] pub logs: Vec<LogEntry>,
      #[n(3)] pub execution_results: Vec<InstructionResult>,   // no #[serde(default)]: required
      #[n(4)] pub result: TransactionResult,
      #[n(5)] pub fee_receipt: FeeReceipt,
      #[n(6)] #[serde(default)] pub total_fees_required: …
  v0.46.0 removes field 3 ("Index 3 is retired"); the indexers' JSON for transactions/<id>/result no
  longer carries it (chain.txt), so 0.45.0's decode of every result fails with 'Failed to deserialize
  response … error decoding response body' (walletd.txt); its manifest dry runs (transactions/dry-run)
  fail the same way, and walletd then submits them anyway, "declaring every input a write".

Release notes, the lines that touch this service (quoted):
  - ⚠️ **Protocol V2**: block headers commit to a transaction merkle root, substate proofs bind to their shard, and foreign pledges are authenticated. Esmeralda activates it at **epoch 12220**; every other network starts at V2 and must be reset. (#2804, #2762, #2798, #2867)
  - ⚠️ **No return values in transaction results**: read component state or events instead. (#2859)
  - ⚠️🔒 **Approving a transaction request needs the wallet's own session**; WebRTC apps need `--enable-webrtc`. (#2855)
  - 🐛 **Transfer proof change** nets out the revealed amount. (#2824)
  - 🐛 **Confidential outputs** finalize against the transaction diff. (#2898)
  - 🐛 **Paying fees with a swap** needs an explicit swap input. (#2837)
  - 🔒 **Indexer failover**: bounded requests, and substates that don't match their id are refused. (#2802, #2813)
  - ⚡ **In-memory locks, block diffs and tree diffs**; databases migrate on first start and can't be opened by an older binary. (#2862, #2863, #2868, #2879)   [validator node section]
  - 🔒 **Transaction results** need committee agreement. (#2838)
  - 🔒 **Rate limits** on all public read routes; checkpoint pages capped at 20. (#2823)
