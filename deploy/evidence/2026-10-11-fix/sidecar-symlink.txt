(Node resolves the main script to /srv/mutis/app/releases/<id>/sidecar/sidecar.mjs, outside the allowed path.
 server/mutis/config.py sidecar_argv() builds exactly this command from sidecar.dir, so mutis-chain would
 fail its sidecar start in production: no canary, no amount proofs, no decoys.)

Fix (deploy): /usr/local/lib/mutis/run-sidecar.sh resolves the real release directory and execs node with it;
/etc/mutis/mutis.toml [sidecar] command = ["/usr/local/lib/mutis/run-sidecar.sh"] (check-config: ok).
